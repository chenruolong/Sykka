# Competitor Activity Weekly Analysis

周报覆盖过去 7 个完整自然日，Asia/Shanghai。输入为 [Activity Log](../activity-log.csv) 和 [Coverage Log](../coverage-log.csv)。先报告覆盖，再解释 Pattern；Coverage 不足时降低结论强度。

文件名使用 `YYYY-Www.md`，例如 `2026-W38.md`。

## 固定结构

1. Executive Summary
2. Monitoring Coverage
3. Messaging Pattern
4. Theme Changes
5. Campaigns
6. Top-performing Content
7. Website Changes
8. Emerging Signals
9. Possible Intelligence Escalation

周报不逐条复述帖子。计数使用“已发现动作数”，X 不称为完整发帖量。互动比较必须说明指标采集时间、缺失值及可比性；没有可靠基线时只展示观察值。

Possible Intelligence Escalation 只列连续 Pattern、重大 Messaging Shift、重要增长玩法、关键官网变化，或与已有 RD / KA / IND 事件构成实质证据关联的事项。每项写明 Content ID、证据、仍不确定什么、建议 NEW / UPDATE / 不升级。最终是否入库由 Intelligence Weekly Maintenance 按 P0 / P1 规则决定。
